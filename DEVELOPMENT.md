# Развитие продукта и Help Center

Новая пользовательская функция TYKK не считается полностью завершённой, пока для неё не создана или не обновлена соответствующая документация Help Center.

Документация должна проверяться по фактическому Desktop UI и поведению той же версии продукта. В статье нельзя заранее описывать будущие кнопки, экраны, интеграции или ограничения. При изменении пользовательского сценария разработчик обновляет связанную статью и, если изменение заметно пользователю, добавляет ссылку на неё в release notes.

Материалы Help не должны раскрывать внутренние детали безопасности и синхронизации или автоматически включать персональные данные учеников, платёжные данные, секреты и необработанные sync payloads.
