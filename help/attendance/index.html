Посещаемость

Что это

Посещаемость — это статус ученика на конкретное занятие и связанное списание в абонементе.

Базовый цикл

  1. Откройте занятие в списке на экране расписания.
  2. Перейдите в список участников.
  3. Выберите нужный статус для ученика: «Присутствовал» / «Опоздал» / «Отсутствовал» / «Болел».
  4. Если смена массовая — примените для всей группы сразу.

Для повторного или корректного изменения используйте действие «Исправить»: старый статус закрывается, и новая отметка становится единственной финальной для этого занятия.

Что важно знать

  • «Присутствовал» ↔ «Опоздал» обычно считается потреблением того же занятия.
  • Перевод в «Отсутствовал» / «Болел» срабатывает как статус без списания для посещения и возвращает ранее списанное занятие в абонемент.
  • Система показывает посещения «без абонемента» как требующие внимания для закрытия на уровне расписания.

Что произойдёт с абонементом

При отметке система автоматически выбирает подходящий абонемент для ученика по сроку действия, группе и доступному остатку. Непотребляющий статус отменяет списание (возврат списания) при корректировке.

Сценарии и ошибки

  • Нет интернета. Статус сохраняется локально и отправляется после синхронизации.
  • Не найдено подходящего абонемента. Отметка сохранится, а непокрытое посещение появится среди ситуаций, требующих внимания.
  • Повторная отметка. Не создавайте вторую самостоятельную посещаемость; используйте исправление.
Статусы конкретного занятия лучше менять из карточки занятия, чтобы не потерять историю корректировки.
