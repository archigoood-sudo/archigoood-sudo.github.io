Посещения

Посещаемость

Что это

Посещаемость — это статус ученика на конкретное занятие и связанное со службой списание в абонементе.

Базовый цикл

  1. Откройте занятие в списке на экране расписания.
  2. Перейдите в список участников.
  3. Выберите нужный статус для ученика: PRESENT / LATE / ABSENT / ILL.
  4. Если смена массовая — примените для всей группы сразу.

Для повторного или корректного изменения используется сценарий correction: старый статус закрывается, и новая отметка становится единственной финальной для этого занятия.

Что важно знать

  • PRESENT ↔ LATE обычно считается потреблением того же занятия.
  • Перевод в ABSENT / ILL срабатывает как непотребляющий статус для посещения и инициирует reversal/возврат в абонементе.
  • Система показывает посещения «без абонемента» как требующие внимания для закрытия на уровне расписания.

Что произойдёт с абонементом

При отметке система автоматически выбирает подходящий абонемент для ученика по правилам активации и применённой валидности. Непотребляющий статус отменяет списание (reversal) при корректировке.

Сценарии и ошибки

  • Нет интернета. Статус сохраняется локально и отправляется после синхронизации.
  • Не найдено подходящего абонемента. Отметка может быть поставлена как attention/attention-only в зависимости от состояния урока.
  • Повторная отметка. Не создавайте вторую самостоятельную посещаемость; используйте correction.
Служебные статусы по конкретному занятию лучше менять из карточки занятия, чтобы не потерять историю корректировки.
