Отчёты

Отчёт по задолженности

Как читать баланс

Отчёт показывает authoritative общий баланс ученика: положительный — долг, отрицательный — отдельный кредит клиента, нулевой — баланс закрыт.

Важно

ТЫК не распределяет общий долг по обязательствам и не выдумывает такую детализацию. Строка отчёта ведёт в карточку ученика для проверки общего баланса.
