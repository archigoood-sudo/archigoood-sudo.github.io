Поиск

Глобальный поиск

Как искать

Введите запрос в верхнее поле «Поиск по студии». Поиск возвращает типизированные результаты по ученикам, контактам, группам, сотрудникам, занятиям и лидам — не более 50 результатов.

Переход

Выберите результат: ТЫК откроет нужную карточку или рабочий раздел. Поиск только читает данные и не создаёт операций или конфликтов.

Офлайн

Без интернет поиск работает по уже синхронизированной локальной проекции и помечает результат как «локально». Локальные ожидающие ученики и лиды видны, но ещё не синхронизированные удалённые данные могут отсутствовать.
