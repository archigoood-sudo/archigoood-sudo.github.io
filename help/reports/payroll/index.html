Отчёты

Отчёт по зарплате тренеров

Что показывает

Отчёт показывает уже существующие расчёты и версии зарплаты тренеров. Он отображает данные, не создавая новый расчёт и не изменяя расчётный период.

Переход

Нажмите строку, чтобы открыть раздел «Финансы» с соответствующим контекстом. Детализацию начислений смотрите в Help по зарплате.
