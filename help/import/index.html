Импорт учеников

Что это

Импорт переносит список учеников из CSV или XLSX без ручного создания каждой карточки.

Как пользоваться

  1. Выберите файл CSV или XLSX в разделе импорта.
  2. Сопоставьте колонки файла с полями ТЫК, например имя ученика, связанный контакт и группа.
  3. Запустите проверку данных.
  4. После проверки подтвердите импорт в доступном интерфейсе.
Место для screenshot сопоставления колонок

Что произойдёт

До импорта данные проходят проверку. Строки из файла будут перенесены в соответствующие поля после подтверждения.

Частые ситуации и ошибки

  • Если колонка не распознана, сопоставьте её вручную с подходящим полем.
  • Перед подтверждением проверьте несколько строк и соответствие контактных данных.
  • Не запускайте повторный импорт только из-за медленной сети: сначала дождитесь результата текущей операции.
