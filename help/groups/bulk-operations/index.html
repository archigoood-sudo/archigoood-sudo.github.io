Массовые операции

Что это

Массовые операции ускоряют работу со списками учеников: массовое добавление, завершение и перевод между группами.

Preview-режим

Перед применением изменений используется предпросмотр результатов:

  • валидны ли данные;
  • есть ли свободные места по целевой группе;
  • есть ли блокирующие зависимости по статусу и конфликтам;
  • какие строки не подойдут.

Это позволяет увидеть итог до применения и сократить неожиданные ошибки в рабочем часу.

Поддерживаемые массовые действия

  • Bulk add — добавить до 100 учеников в группу одним разом.
  • Bulk end — завершить активные членства для выбранных учеников.
  • Bulk transfer — перевести учеников из источника в цель одной операцией.

Результаты по строкам

  • APPLIED — операция применена успешно.
  • SKIPPED — строка не затронута, потому что данные уже в требуемом состоянии или конфликтов не требует изменений.
  • FAILED — ошибка валидации/конфликта для этой строки, строка не изменена.

Каждая строка хранит один детерминированный итог, поэтому повторный запуск по тем же данным возвращает тот же результат.

Ограничения

  • Размер пакета не превышает 100 учеников.
  • Для каждой строки проверяется актуальность статуса перед применением.
  • Новые членства не создаются для INACTIVE/ARCHIVED учеников или групп.
