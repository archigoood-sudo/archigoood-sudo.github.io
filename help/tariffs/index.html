Тарифы

Что хранит тариф

Тариф — повторно используемый набор условий для выдачи абонемента: название, тип, стоимость, срок действия, количество занятий, доступные дни заморозки и область действия.

Типы тарифов

  • Пакет занятий (package / LESSON_PACK) — заданное количество занятий.
  • Безлимитный (unlimited / UNLIMITED) — без числового лимита посещений.
  • Разовое занятие (single-visit / SINGLE_LESSON) — одно занятие.

Область действия

  • Все филиалы (global) — тариф доступен во всей организации.
  • Один филиал (branch) — тариф доступен ученикам через их актуальную группу в выбранном филиале.

Условия выданного абонемента

При выдаче ТЫК сохраняет снимок версии тарифа. Последующее изменение или архивирование каталога не меняет цену, срок, лимит и другие условия уже выданного абонемента.
