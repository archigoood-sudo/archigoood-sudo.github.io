Что это

Отдельная x64-сборка ТЫК для компьютеров Mac с процессором Intel.

Как установить и открыть

  1. На официальной странице загрузки под кнопкой macOS выберите «версия для Intel».
  2. Откройте DMG и перенесите приложение в папку «Программы», если это показано в установщике.
  3. Попробуйте открыть ТЫК. Если macOS блокирует неподписанную сборку, закройте предупреждение.
  4. Откройте меню Apple → «Системные настройки» → «Конфиденциальность и безопасность», найдите сообщение о ТЫК и выберите «Всё равно открыть».
  5. Проверьте название приложения и подтвердите повторный запуск штатной кнопкой.

Что произойдёт

Разрешение сохранится как исключение для ТЫК. Системная защита останется включённой.

Частые ситуации и ошибки

  • Если кнопка исключения не появилась, сначала повторите попытку запуска ТЫК.
  • Если загружена версия Apple Silicon, удалите её и скачайте Intel-сборку.
  • Сообщение о повреждении или вредоносном ПО не обходите — скачайте файл заново с tykk.ru и при повторении обратитесь в поддержку.
