Windows x64

Версия 0.1.0 BETAБез цифровой подписи

Что это

64-битная тестовая сборка ТЫК для Windows 10 и 11. SmartScreen может показать предупреждение о неизвестном издателе.

Как установить и открыть

  1. Скачайте Windows x64-сборку только с официальной страницы ТЫК.
  2. Откройте загруженный EXE.
  3. Если SmartScreen показывает предупреждение о неизвестном приложении, ещё раз проверьте, что файл получен с tykk.ru.
  4. Если в вашем предупреждении доступно «Подробнее», откройте подробности и выберите штатное действие запуска. В разных версиях Windows текст может отличаться.
  5. Завершите шаги установщика и откройте ТЫК обычным способом.

Не отключайте SmartScreen, Microsoft Defender или защиту Windows. Если организация управляет вашим компьютером и запуск запрещён политикой, обратитесь к системному администратору.

Что произойдёт

Windows запустит выбранный установщик, не отключая защиту для остальных файлов и приложений.

Частые ситуации и ошибки

  • Нет действия запуска. Не меняйте настройки безопасности целиком; убедитесь, что файл официальный, или обратитесь к администратору/поддержке.
  • Defender сообщает об обнаруженной угрозе. Не восстанавливайте и не добавляйте файл в исключения. Сообщите в поддержку и приложите безопасный снимок экрана.
  • Система не 64-битная. Текущая Windows-сборка не подходит.
