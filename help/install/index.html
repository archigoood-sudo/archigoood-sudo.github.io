Установка ТЫК

Текущая тестовая версия распространяется без цифровой подписи. Поэтому при первом запуске macOS или Windows может показать предупреждение — само по себе оно не говорит, что файл вредоносен или повреждён.

Скачивайте ТЫК только с официальной страницы tykk.ru. Не отключайте Gatekeeper, SmartScreen, Defender или другую системную защиту.

Как выбрать версию

На Mac откройте меню Apple → «Об этом Mac» и посмотрите строку с чипом или процессором. Если указан Apple M-серии — выбирайте Apple Silicon; если Intel — версию Intel. На Windows текущая сборка предназначена для 64-битной системы.

Что произойдёт

После установки ТЫК появится среди приложений. При первом запуске система дополнительно попросит подтвердить открытие неподписанного приложения. Подтверждайте его только если файл был скачан с tykk.ru.
