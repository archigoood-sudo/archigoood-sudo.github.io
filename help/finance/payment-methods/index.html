Способы оплаты

Доступные варианты

  • «Наличные» — наличные.
  • «Карта» — карта, получение подтверждено вручную.
  • «СБП» — СБП, получение подтверждено вручную.
  • «Другое» — другой способ.

Почему важно выбрать верно

Экран Поступления по способам использует выбранное значение для дневной разбивки. Если способ указан ошибочно, примените исправление оплаты с причиной.
