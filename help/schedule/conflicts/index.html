Конфликтная проверка

Конфликты зала и тренера

Что это

Если выбранное время уже занято, система блокирует сохранение и показывает business error по конфликту.

Типы конфликтов

  • Тренер одновременно назначен на два пересекающихся занятия.
  • Зал уже используется другим занятием в это время.
  • Группа имеет пересечение по времени в другой ячейке расписания.

Как исправить

  1. Выберите другое время/зал/тренера для нового/переносимого занятия.
  2. Для серии решите, где менять всю серию, а где только конкретное occurrence.
  3. Сохраните после снятия конфликта.

Результат

После сохранения конфликтный элемент превращается в полноценный плановый урок со статусом SCHEDULED.
