Как перенести занятие

Что это

Перенос меняет дату/время конкретного занятия. Для серий можно перенести весь набор или только одно занятие серии.

Как перенести

  1. Откройте занятие, которое нужно перенести.
  2. Выберите действие «Перенос».
  3. Выберите новую дату/время.
  4. Подтвердите, переносится ли только это событие или вся серия.

При переносе одного занятия серии записи по другим датам остаются без изменений.

Ограничения

  • Если новое время даёт конфликт зала/тренера/группы, перенос блокируется до решения.
  • Для уже завершённого урока перенос обычно идёт через корректировку/пересоздание бизнес-правилами приложения.
